# Fjall 3 存储格式

Status: decided

MMDB 使用 Fjall 3 创建本地数据目录。应用可以关闭并重开这些目录，按原身份读回记忆、来源、会话日志和运行状态。受管存储、多模型库、独立运行状态与 blob 元数据各自保有现有的目录所有权。

## 行为

- 普通打开遇到 Fjall 2 会报告不兼容的目录。调用方可以保留它，另建空库。受管目录也可以显式确认整库重置，取得隔离位置，再用原版本读取旧记录。新库从空数据开始。
- 多模型库的一次时间索引查询、元数据查询或入边查询，从同一已提交版本读取索引和对应记录。读取结束即释放该版本。
- 回收中断上传或已清除记录的载荷时，按块键和既有预算删除。读取正文时仍按块校验和分页。记忆模块重置后，原会话日志继续可读。
- 已确认的写入在重开后可见。操作回执、运行状态的修订检查、提交结果未知时的确认与恢复，继续由各自的 MMDB 模块负责。

## 决策

- 项目处于 startup。旧库处理采用保留原目录、显式换空库的方式。转换历史记录、在打开时清空目录都会改变这个恢复契约。
- 大块记录载荷由存储引擎分离键和值，便于只扫描块键和独立回收旧值。内容寻址的 blob 继续用哈希、引用计数与文件管理，向量快照继续由向量存储管理。两者均有独立于记录载荷的生命周期。
